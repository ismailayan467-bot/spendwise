# SpendWise

## Project Description
SpendWise is a personal expense and budget tracking web application designed to help users record daily expenses, categorize spending, and monitor their overall financial balance.

## Technologies Used
### Frontend
- HTML5
- CSS3
- JavaScript
- github
- Netlify

### Deployment & Version Control
- GitHub (Version Control & Repository Hosting)
- Netlify (Continuous Deployment & Live Web Hosting)

## GitHub Repository Information
- **Repository Link:** https://github.com/ismailayan467-bot
- **Branch:** main

## Live Netlify Website URL
- **Live Site:** https://app.netlify.com/projects/spendwise-ayan/domain-management

## Deployment Process Summary
1. Organized project files in the root directory and verified all relative file paths.
2. Created a public GitHub repository (`spendwise`) and uploaded the source code.
3. Connected the GitHub repository to Netlify for automated cloud deployment.
4. Customized the Netlify subdomain to `spendwise-ayan.netlify.app` and verified continuous deployment via a test commit.

## Challenges Encountered During Deployment
Navigating the Netlify interface to locate the project overview and custom subdomain settings initially took some exploration, and verifying that relative file paths and repository links pointed to the root directory rather than local computer paths required careful checking.

## Lessons Learned
- How GitHub and Netlify integrate to provide seamless continuous deployment whenever changes are committed to the `main` branch.
- The importance of keeping `index.html` in the root folder and using relative paths so websites render properly on live servers.
